# Selenide Quiz 🧪

Інтерактивний квіз для перевірки знань Selenide API — 100 запитань із перемішуванням.

## Запуск

### Варіант 1 — Python (є на будь-якому Mac/Linux)
```bash
cd selenide-quiz
python3 -m http.server 8080
```
Відкрий: http://localhost:8080

### Варіант 2 — Node.js (npx)
```bash
cd selenide-quiz
npx serve .
```
Відкрий: http://localhost:3000

### Варіант 3 — просто відкрити файл
Просто двічі клікни на `index.html` — відкриється у браузері.
(Шрифти завантажуються з Google Fonts, потрібен інтернет)

## Структура
```
selenide-quiz/
├── index.html   — розмітка
├── style.css    — стилі (dark theme, JetBrains Mono)
├── quiz.js      — логіка + 100 запитань
└── README.md
```

## Фічі
- 100 запитань по Selenide API
- Fisher-Yates shuffle — порядок запитань і варіантів відповідей перемішується при кожному старті
- Кнопка «Фініш» — зупинись будь-коли, результат рахується відносно пройдених запитань
- Пояснення після кожної відповіді
- Прогрес-бар та лічильник у хедері
